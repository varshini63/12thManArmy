# ClaimWatcheR  
### Decentralized Insurance Fraud Detection using Blockchain, SSI, AI & Federated Learning

## 📌 Overview
ClaimWatcheR is a smart decentralized insurance platform designed to detect and prevent fraudulent insurance claims.  
It integrates **Blockchain**, **Self-Sovereign Identity (SSI)**, **Artificial Intelligence**, and **Federated Learning** to create a transparent, secure, and privacy-preserving insurance ecosystem.

The system connects **patients, hospitals, and insurers** through a trusted blockchain network and automates claim verification using AI.

---

## 🚀 Key Features
- 🔐 Self-Sovereign Identity for secure user verification  
- ⛓ Blockchain-based policy & claim tracking  
- 🤖 AI-powered fraud detection and claim scoring  
- 🧠 Federated learning for privacy-preserving model improvement  
- 📄 Document hashing for tamper-proof verification  
- ⚡ Smart contract automation for faster claim processing  
- 👥 Role-based dashboards (Patient, Hospital, Insurer)

---

## 🏗 Architecture Flow
1. User creates SSI-based digital identity  
2. Policy issued via blockchain smart contract  
3. Hospital submits claim & documents  
4. Document hash stored on blockchain  
5. AI engine evaluates claim and gives fraud score  
6. Insurer approves/rejects claim  
7. Federated learning updates fraud model
